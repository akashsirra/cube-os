# CUBE//OS

A next-generation interactive Rubik's Cube experience where solving, learning, AI, and visualization come together.

## Vision
CUBE//OS is being built as a visual cube laboratory—not just another cube simulator.

## Roadmap
- [ ] Core cube state engine
- [ ] Move notation and validation
- [ ] Scramble / undo / redo
- [ ] Interactive 3D cube
- [ ] Replay timeline and ghost solves
- [ ] X-ray/internal cube visualization
- [ ] Solver
- [ ] AI coaching
- [ ] Solve analytics and generative visualization

## Development
The project is intentionally starting with the cube engine before the visual layer so every later feature can rely on a correct, testable state model.
